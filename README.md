# Welcome to Lizhen's World

國立清華大學學習科學與科技研究所碩士班申請用互動式自述網站，使用 HTML、CSS、Vanilla JavaScript，無需安裝 Node.js。

## 執行

在專案資料夾內執行 `python -m http.server 8000`，開啟 http://localhost:8000 。也可直接開啟 `index.html`，但建議使用本機 HTTP 伺服器，避免部分瀏覽器限制媒體載入。

## 部署

整個資料夾上傳至 GitHub Pages、Netlify 或 Vercel 靜態網站即可。入口為 `index.html`，素材均採相對路徑。

## 素材與開場處理

- 五張原始角色 JPG 已製作為透明 WebP。為保留原始畫風，去背以背景連通區判斷及邊緣平滑處理，不保證所有淡色髮絲像素完全無邊，應人工逐張檢視。
- 原始開場 `06.mp4` 是**黑色不透明背景**，不是透明影片。網站會將原片在隱藏 video 元素中播放，逐幀繪到 Canvas，以亮度摳黑底並呈現在首頁。這是「即時色鍵去背備援」，**不是完成的專業逐幀語意去背或 WebM Alpha**；暗色細節及髮絲邊緣可能有瑕疵，需要專業透明素材時可替換 Canvas 流程。
- 影片開始前及播放期間不顯示 01～05 圖層；結束或跳過後只顯示 05，啟用 01～04 Hover。頁面初始 DOM 會載入 05，但 CSS 使其不參與可見畫面合成；開場階段切換功能關閉。
- 自動播放若受瀏覽器限制會直接顯示預設人物、啟用互動。
- 使用 `prefers-reduced-motion` 的使用者自動跳過動畫。

## 作品來源

assets/projects 內的圖片擷取自使用者提供的原始作品 PDF，均是報告頁面，不是新生成的介面；部分圖片可能含報告文字。未提供的 Scheme Interpreter 真實圖片不虛構。

## 重要註記

此網站為招生自述延伸；團隊作品均保留分工說明。研究方向互動題目是寫死的概念示範，並非真的接入 AI。

## V3.1 開場影片修復
- 已移除 Canvas 逐影格去背，改為直接用 `<video autoplay muted playsinline>` 播放。
- 提供自動播放失敗時的「點擊播放影片」控制，以及跳過開場。
- 所附 MP4 是 H.264/yuv420p，**不含原生 alpha 透明通道**，且影格背景實際為黑色；目前以 `mix-blend-mode: screen` 讓黑底融入奶油白，若後續提供真正含 alpha 的 WebM，可直接取代並移除混合模式。


## V3.2 透明開場影片
- 使用使用者提供的 `assets/videos/06.webm`（VP9 Alpha）。
- 已確認 Alpha 通道存在；移除 CSS screen 混合模式，以原始透明像素與奶油白背景合成。
- 不需要 Canvas 去背。需要使用支援 VP9 Alpha 的瀏覽器，例如較新版本 Chrome。
- 開場播放完成才顯示人物圖片並啟用 Hover。


## V3.3 進場人物標籤動畫

- 使用原生透明 `assets/videos/06.webm`，不使用 Canvas 去背或 blend mode。
- 影片約 5.16 秒，標籤依 `video.currentTime / video.duration` 精準跟隨播放進度；可在 `js/main.js` 修改 `cuePoints`。
- 播放期間 `cards-area` 保持隱藏、`inert`，不顯示四張互動卡片；片尾才揭示。
- 已移除「跳過開場」，但若瀏覽器阻擋 autoplay，會出現「播放我的故事」按鈕，以免訪客卡住。影片失敗時顯示可閱讀的首頁備援。
- 不更換角色，也不對影片做縮放動態；氣泡與 HTML 獨立動畫。
